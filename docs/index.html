Chores

Pick a chore. See exactly what it eats.

Each cleanup has its own room in Grub, with a dry run first and a checklist before anything goes.

Clean

Clears out the caches, logs and temp files your Mac piles up, plus scraps from apps you already deleted.

What it eats

  • User caches
  • System caches
  • Logs
  • Temporary files
  • Leftovers from deleted apps
  • Sniff first runs a dry run that lists what would go and deletes nothing.
  • Anything you protect stays protected.
  • Tidy up on the Status screen runs Clean and then Optimize in one go.

Uninstall

Removes an app along with the support files, caches and preferences it leaves scattered around your Mac.

What it eats

  • The app
  • Application Support
  • Caches
  • Preferences
  • Other leftovers
  • A review sheet shows every file before anything is removed.
  • Everything lands in the Trash, so you can change your mind.
  • Apps are listed by size, with search, so the big ones are easy to find.

Purge projects

Finds build artifacts in code projects you no longer touch. They can run to gigabytes, and running a project again just rebuilds them.

What it eats

  • node_modules
  • target
  • dist
  • .next
  • build folders
  • Scans your usual code folders for build artifacts.
  • You tick each one on a checklist before Grub removes it.

AI tools

Coding assistants pile up old versions, caches, chats and worktrees. Grub finds what they leave behind and never lists anything used in the last day.

What it eats

  • Old versions
  • Caches and logs
  • Old or orphaned sessions
  • Finished worktrees
  • Oversized OpenCode database
  • Caches and logs come ticked. Sessions you pick one by one, with a retention setting per tool.
  • Only clean Claude Code worktrees are offered, removed with git worktree remove.
  • Files go to the Trash. Codex sessions are copied to the Trash, then deleted with Codex's own command.

Installers

Finds the disk images and installer packages you downloaded, installed and forgot about.

What it eats

  • .dmg
  • .pkg
  • Looks in Downloads, Desktop and the other usual spots.
  • You choose which installers to remove.

Optimize

Refreshes system caches and services and fixes safe maintenance issues, for when your Mac feels sluggish.

What it does

  • Rebuilds stale caches
  • Refreshes services that act up
  • Safe maintenance fixes
  • Some steps need your Mac password. Grub asks in its own window, passes it straight to sudo and never stores it.
  • Open the real terminal any time to watch every command run.

Looks after the rest of your Mac, too.

The small jobs that usually mean digging through System Settings or the terminal.

  • Startup items

    Every login item and launch agent in one list. Switch off your own agents, and find the system ones in Finder.

  • Updates

    Outdated Homebrew apps and tools, upgraded in the terminal so you can see what happens.

  • Menu bar

    CPU and free space at a glance, with a popover of live stats and quick actions. Close the window and Grub stays up there.

  • History

    A food diary of every cleanup Grub has done on this Mac, and how much space it freed.

Nothing goes without your say.

A cleaner should never surprise you. Every chore follows the same careful path.

  1. Sniff

    A dry run shows exactly what would go. Nothing is touched.

  2. Review

    Checklists and review sheets let you untick anything you want to keep.

  3. Trash

    Removed files go to the Trash where Grub can, so you can change your mind.

  4. Watch

    Open the real terminal any time, and check History for every cleanup since.

Install

Up and running in a minute.

Grub is a free download. Setup walks you through the few permissions a cleaner needs.

Install

  1. Download Grub, or pick a version from the releases page.
  2. Drag Grub to Applications and open it.
  3. Follow setup. It takes about a minute, and you can run it again from About.
Build it from source 
# needs Homebrew and Node
brew install mole
git clone https://github.com/nkrrish/grub
cd grub && npm install && npm start

What setup asks for

  • Mole, the cleaning engine. Grub installs it with Homebrew if it's missing.
  • Full Disk Access, so Grub can see the caches and leftovers it cleans.
  • System Events access, to list your login items.
  • Open at login and daily Mole updates. Both optional.
