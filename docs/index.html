Features

Everything a tidy Mac needs

Grub's core cleaning runs on Mole, a battle-tested open-source engine. Grub gives it a home: dashboards, checklists and a review step before anything goes.

Health at a glance

Live CPU, memory, disk, battery and network, plus CPU and free space in your menu bar.

Disk map

See what's taking up space and dig into any folder to find the culprits.

Guided cleanups

Caches, logs, old installers and build leftovers, with progress you can follow. Tidy up cleans and optimizes in one go.

Full uninstalls

Remove an app along with the support files it leaves behind, after you review the list.

Startup control

See every login item and launch agent, and switch off the ones you don't need.

AI tools cleanup

Clears old versions, caches, stale sessions and finished worktrees from Claude Code, Codex, Cursor and OpenCode.

Safety

Careful by design

A cleaner should never surprise you. Grub shows its work and asks before it acts.

Sniff first

Run any cleanup as a dry run to see exactly what would go before anything is touched.

Your password stays yours

Admin steps ask in Grub's own window and pass it straight to sudo. It's never stored.

Watch it work

Open the real terminal any time and see every command Grub runs.

Open source, notarized

Install

Get Grub

Grub is a free download. It works on macOS 12 Monterey or later.

  1. Download Grub, or pick a version from the releases page.
  2. Drag Grub to Applications and open it.
  3. Follow setup. Grub installs the Mole engine if you don't have it and walks you through Full Disk Access.

Build it yourself:

# needs Homebrew and Node
brew install mole
git clone https://github.com/nkrrish/grub
cd grub && npm install && npm start
